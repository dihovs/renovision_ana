# The full object catalogue — target list

**This is OUR catalogue, not a transcription of theirs.** magicplan ships 666
items across 14 categories (see `reference/magicplan/object-model.md`) and
publishes no list of them; the names below are built from three things: the
17 door names read off the owner's own screenshots, the representative items
their help centre does publish, and what this trade actually meets on a job.

**296 items.** Not 666 — deliberately. A large part of their library is
school desks, retail fitting rooms, swimming pools and COVID floor markers,
which cost the same to draw as a sump pump and earn nothing on a claim. This
list is sized to never leave a crew stuck.
